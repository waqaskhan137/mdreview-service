## Decision log

### D1 (#288) — precondition compare lives in ReviewService.put_source, not the PUT arm
**Decided:** the expected-revision compare sits at the top of `ReviewService.put_source`, raising
`ReviewWriteRejected(status=409)`, with the HTTP arm only parsing If-Match / the
`expected_revision` body key into an int. The caller already holds `store.lock` (the method's
documented contract), so the compare is atomic with the snapshot+overwrite, and the latex
decorator (`LatexAwareReviews.put_source`, widened in the same change) inherits the guard through
`self._inner.put_source` with zero duplicated logic.
**Falsified if:** a put_source caller appears that does not hold store.lock (the compare would
race), or a 409 is observed with a partial write (snapshot taken, source not replaced).

### D2 (#288) — MCP transport for the token: body key in, opt-in envelope out
**Decided:** `update_source` sends `expected_revision` as a PUT body key (route() stays a pure
(method, path, body) mapping; an old server drops the key, an old wrapper never sends it), and
`get_source` gains `with_revision=true` returning `{"source", "revision"}` built from ONE
response (body + ETag), never two fetches. The default `get_source` result stays the raw
document verbatim; the epic forbids a default-on envelope as a breaking change.
**Falsified if:** an existing agent's `update_source` body changes byte-wise when the parameter
is omitted (pinned by a test), or the envelope's revision can disagree with the text it
accompanies.

### D7 (#289) — CSRF predicate composed in build_hosted, not core's _csrf_ok
**Decided:** the PUT /source arm reaches a bound `app.check_csrf` composed in `build_hosted`
(next to `app.sessions`) via `getattr`, per the epic's stated seam — not by reusing core's
`_csrf_ok` (#266), which has the same semantics but lazily imports `mdreview.hosted.sessions`
inside core. The bound seam keeps the session logic in the hosted composition; on the local
tier the attribute is absent, so there is no gate on a tier with no cookie plane, and the core
import graph is pinned by a test (`mdreview.server` never pulls in `mdreview.hosted`). The
predicate returns a bool and the arm writes the 403, so response rendering stays in core like
every module-rejection path.
**Falsified if:** the local tier ever gains `app.check_csrf` (a gate would arm where no cookie
plane exists), or a proxy-vouched / bearer PUT is 403'd for a missing token (round-1 finding 1
rebuilt — the selfcheck's mutation row for exactly this kills a plane-keyed gate).

### D8 (#289) — round.json "by" copied only when the outgoing meta carries the key
**Decided:** `snapshot_round` copies `by` from the outgoing meta before the overwrite ONLY when
`source_updated_by` is present; an agent-authored draft archives with no key and readers
default "agent", the same reader rule as `/status`. Writing `by: "agent"` unconditionally would
have broken the all-agent byte-identical AC on disk and on `GET /history` — the epic exempts
only `GET /status`. Verified: the oracle's history row shows zero drift, and the selfcheck's
all-agent no-trace row fails under a set-both-values mutation.
**Falsified if:** a round that archived a reviewer draft lacks `by`, or an all-agent review's
round.json / history response gains bytes vs origin/dev.
